# 设计说明



## 配色方案

- 主色：#AEA7D9
- 辅助色：#9F8FD9 #8E79D7
- 强调色：#BDD9F2 #ACE5F2



## 字体

- 标题：黑体
- 正文：宋体



## 核心页面

- ### 首页

  **板块内容：**

  顶部搜索栏

  服务快捷入口（美容、上门遛狗、寄养、紧急救助等）-网格布局

  社交动态帖子展示（封面、用户名、点赞数）-瀑布流布局

  导航栏（首页、快捷发帖、个人中心）

  

- ### 搜索页

  **板块内容**：

  搜索栏

  历史搜索

  热搜标签

  **交互说明**：

  具体搜索页面，可根据所需信息性质进行筛选

  

- ### 服务列表页

  **板块内容：**

  顶部分类筛选（距离、评分、价格等）

  对应服务店铺（商家logo、名字、位置）-列表布局

  

- ### 服务商家详情页

  **板块内容：**

  商户店铺图片轮播

  名称、地址、电话、评分

  服务项目

  用户评价

  底部预约

  

- ### 预约表单页

  **板块内容**：

  服务项目选择

  预约时间选择

  备注输入框

  提交按钮

  **交互说明**：

  选择时间 → 弹出时间选择器

  提交 → 跳转订单列表页

  

- ### 社交动态帖子详情页

  **板块内容：**

  动态完整内容（图文）

  话题标签

  点赞/评论/收藏按钮

  评论列表（头像+昵称+评论内容+时间）

  底部输入框（写评论）

  

- ### 帖子发布页

  **板块内容：**

  动态文字内容

  动态图片内容

  标签项

  

- ### 个人中心详情页

  头像+昵称+简介

  关注数、粉丝数、获赞数

  动态/收藏/订单/消息切换

  动态卡片列表

  **交互说明**：

  点击关注数 → 跳转关注列表页

  点击动态/收藏/订单/消息 → 切换内容

  点击动态卡片 → 跳转详情页

  

- ### 消息详情页

  **板块内容**：

  消息列表（评论、点赞、系统通知、商家/用户信息）

  每条消息：头像+内容+时间

  **交互说明**：

  点击各条消息，会进入详情页面

  点击预约消息，会跳转到订单页面



## 交互说明





| 全局交互操作 | 交互反馈                                    |
| :----------- | :------------------------------------------ |
| 下拉刷新     | 列表页支持下拉刷新，顶部出现加载动画        |
| 上拉加载     | 列表滚动到底部自动加载下一页数据            |
| 未登录操作   | 点击点赞/收藏/评论等需登录操作 → 跳转登录页 |
| 返回按钮     | 所有二级页面左上角返回箭头                  |
| 底部导航     | 首页、动态发布、消息、我的                  |
| Toast提示    | 操作成功/失败等轻提示                       |
| 加载占位     | 数据加载时显示骨架屏或加载中动画            |
