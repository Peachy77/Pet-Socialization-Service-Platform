## 心得体会

学习是个figma，不再是纯手搓UI设计图，Figma AI能快速生成初稿，但额度有限、细节需要人工调整。可以先让AI搭框架，再手动优化细节，效率最高。但是想要更高效的利用ai功能，必须事先理清楚需求的功能点和页面，才更有利于ai帮我们生成初始框架，减少返工。
